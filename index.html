    Tentang model

    Proyek asli memakai K-Nearest Neighbors dengan fitur Kehamilan, Glukosa, Ketebalan Kulit, IMT, dan Usia. Tekanan darah, insulin, dan fungsi silsilah dibuang saat seleksi fitur.

    Halaman ini berjalan sepenuhnya di browser, jadi file model (.pkl) tidak bisa dimuat. Hitungannya memakai pendekatan regresi logistik dengan bobot perkiraan dari pola dataset yang sama. Untuk hasil identik dengan model KNN Anda, jalankan model lewat Gradio, Hugging Face Spaces, atau Flask.

    Alat ini hanya untuk pembelajaran. Hasilnya bukan diagnosis medis. Periksakan kadar gula darah Anda ke dokter atau laboratorium.
